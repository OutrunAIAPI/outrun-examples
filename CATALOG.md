# Outrun model catalog

> Every active model on Outrun, with the exact model ID to send to `https://api.outrun.to/v1` and a link to its page (price, context, setup values).
> Generated by `scripts/update_catalog.py` from the public feed https://api.outrun.to/pricing. Paused models are left out.

- Models: 81 (plus 14 alternative route IDs)
- Live prices: [https://outrun.to/model/](https://outrun.to/model/?utm_source=github&utm_medium=repo&utm_campaign=examples)
- Machine-readable summary: [https://outrun.to/llms.txt](https://outrun.to/llms.txt?utm_source=github&utm_medium=repo&utm_campaign=examples)

Route IDs are the same model through another route at a different price; the model page compares them.
